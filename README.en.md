A frontend AI rules Starter for Codex and Claude Code. It keeps project facts, task routing, design workflow, implementation workflow, and acceptance evidence in the repository so agents read constraints first and report with proof.

## Choose an entry point

| Goal | Entry point | Guide |
| --- | --- | --- |
| Install the Starter | `node scripts/build-starter.mjs --target <dir>` | [Operations](docs/operations/OPERATIONS.en.md) |
| Initialize project profile and component catalog | `$project-profile` | [Task overview](docs/tasks/README.en.md) |
| Run professional visual design and freeze a design version | `$design-task` | [Design Task guide](docs/tasks/DESIGN-TASK.en.md) |
| Turn requirements, screenshots, prototypes, Figma, or HTML into a page | `$frontend-task` | [Frontend Task guide](docs/tasks/FRONTEND-TASK.en.md) |
| Upgrade bundled Skills, plugins, or mirrors | `node scripts/update-vendored.mjs` | [Upgrades and CI](docs/operations/UPGRADING.en.md) |
| Review bundled capabilities and external plugins | — | [Capability inventory](docs/operations/BUILT-IN-CAPABILITIES.en.md) |

## Shortest path

```bash
node scripts/build-starter.mjs --target ./my-project
node scripts/build-starter.mjs --check
node .toolkit/scripts/check-ai-guidance.mjs --root . --strict
node .toolkit/scripts/sync-mirror.mjs --check

$frontend-task inspect
$frontend-task plan
$frontend-task confirm
$frontend-task implement
$frontend-task verify
$frontend-task report
```

## Core rules

- `.agents/skills/` is the editable Skill source; `.claude/skills/` is an autogenerated mirror.
- Project facts come from the profile, component catalog, code, tests, and API contracts; external design material only owns the facts it explicitly covers.
- Page tasks read the profile, `deliveryTargets`, component catalog, and page rules before `inspect`.
- High-impact decisions require confirmation before implementation; unverified items must be reported as unverified.
- The root README is navigation only. Task procedures live in `docs/tasks/`; maintenance procedures live in `docs/operations/`.

## Layout

```text
.agents/skills/        Editable Skill source
.claude/skills/        Autogenerated Claude Code mirror
.toolkit/              Validators, mirror scripts, and runtime files
scripts/               Starter build, upgrade, and removal tools
docs/tasks/            Design and frontend task guides
docs/operations/       Installation, capabilities, upgrades, CI, and troubleshooting
toolkit.json           Version, Skill roster, vendored sources, and release manifest
```

Maintainers start with the [operations guide](docs/operations/README.en.md); task authors start with the [task guide](docs/tasks/README.en.md).
