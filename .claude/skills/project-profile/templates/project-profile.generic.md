# 项目画像

本文件集中保存项目专属事实。先填写本文件，再启用严格 AI 指引门禁。相同事实不要在多个提示词中重复定义。

模板选择初始状态为 `pending`；本模板只是 generic 候选，不代表框架已确认。首次使用 `$project-profile` 必须同时展示 `generic`、`react`、`vue` 并由用户选择或暂缓；所有 `<待填写>` 字段都必须依据仓库证据或用户决定填写。

在当前仓库生成 `docs/PROJECT_PROFILE.md`；尚无工程时保留草案，已授权的工程搭建完成后再更新实际目录和命令。指引校验使用 `node .toolkit/scripts/check-ai-guidance.mjs --root .`。

组件目录由 `$project-profile components` 单独初始化。generic 项目的推荐规划基线为框架中立的 Shell、Button、Form、DataDisplay、Feedback、Icon 契约；必须由用户明确选择后才能写入目录，规划候选不等于已实现组件。
