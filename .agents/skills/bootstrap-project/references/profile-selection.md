# 画像选择

先读取目标 `docs/PROJECT_PROFILE.md`，存在时以其为基线，逐字段补充，不自动重建。首次初始化时始终展示当前资源清单中的 generic、React、Vue 候选，并要求用户确认模板；用户此前明确提到的框架或模板只能作为预选项和推荐依据，不能替代本次初始化确认。模板重构或迁移需要用户明确选择。

不存在时，读取当前仓库资源清单中的 profiles：React、Vue、generic，或按相同章节自动生成。用户已指定框架或模板时直接使用；未指定时依据代码提出候选，只有无法确定且会影响结果时才询问。仅有模板资源、尚无工程的目录不得推断运行时或质量命令；已授权创建工程时先记录草案，创建后依据实际配置更新，不要求全部工程事实先于工程存在。

模板选择不代表批准其全部预设。React/Vue 模板的依赖、路径、图标、主题、语言和命令均须对照目标事实；不匹配项列入字段差异。非前端项目可以使用 generic 并明确不适用项，不能用单个手机尺寸代替多端范围。

输出：画像来源、证据文件、现有画像处理策略。模板缺失或来源不可读时报告缺口，不用相似文件冒充。继续读取 [字段与证据](profile-schema.md)。
