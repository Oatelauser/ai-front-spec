# 验收矩阵

本文件把“完成”转换成可执行检查。范围依据 [共用契约](common-workflow.md)、项目画像的 UI/接口矩阵、组件目录、任务类型、影响模式和实际来源证据。

## 1. 验收前置

开始前列出：任务类型、影响模式、实际路由、角色、来源版本、浏览器、CSS 视口、DPR、主题/语言、数据环境、页面状态和操作预期。按 `deliveryTargets` 与页面声明生成：

- `sourceViewport`：来源实际覆盖的视口；
- `confirmedTargets`：项目画像或用户确认的目标端；
- `derivedTargets`：按现有规则推导的端；
- `unverifiedTargets`：尚无证据的端。

每项记录 `passed`、`failed`、`unverified` 或 `not-applicable`；不适用必须有依据，环境缺失属于未验证。

## 2. 按任务类型和影响模式选检查

| 任务/影响 | 必须验证 |
| --- | --- |
| `new-page` | 主流程、目标状态、路由/刷新、组件和适用接口 |
| `incremental` | 变化区域、邻近区域、受影响调用方和原行为 |
| `bug-fix` | 原复现、修复结果、邻近正常路径和回归测试 |
| `refactor` | 路由、行为、数据、权限、状态、视觉基线的外部等价 |
| `visual` | 来源视口逐区域对比、字体、Token、图标、图片、资产和状态 |
| `behavior` | 导航、返回、表单、筛选、分页、弹层和状态转换 |
| `data` | 请求、字段、loading/empty/error/unauthorized/forbidden/success/retry、缓存和重复操作 |
| `structure` | 构建、调用方、共享组件、路由入口和依赖回归 |
| `compatibility` | 目标端、断点、主题、键盘、触摸、无障碍、溢出、安全区域和短屏 |

## 3. 分层完成状态

必须分别报告：

```text
visual: passed / failed / unverified
behavior: passed / failed / unverified
data: passed / failed / unverified
engineering: passed / failed / unverified
```

只有本次必需层级均有通过证据，或用户明确缩小完成范围，才能报告对应范围完成。视觉通过不代表交互或业务完成；HTTP 200、构建成功、mock 成功或截图生成也不能替代其他层级。

## 4. 视觉和响应式

有设计源时，先在来源视口比对，再检查确认目标端和关键断点。记录来源截图、实现截图、视口/DPR、状态、逐区域差异和剩余问题。检查：

- 容器、布局骨架、对齐线、滚动容器、固定/吸附关系；
- 字体、字重、行高、颜色、Token、边框、圆角、阴影；
- 图片尺寸、比例、裁剪、加载失败和替代文本；
- 长标题、长英文、无空格字符串、大数值、零值和缺失可选字段；
- 主题、语言、短屏、横向溢出、触摸目标和 reduced-motion。

## 5. 交互、无障碍及接口

| 场景 | 实际检查 |
| --- | --- |
| 导航 | 列表到详情、面包屑、前进后退、深链和刷新 |
| 表单 | 必填、跨字段校验、错误定位、重复提交、取消、失败重试和输入保留 |
| 弹层 | 初始焦点、键盘访问、Escape、焦点返回和滚动锁 |
| 可访问性 | 原生语义、Tab 顺序、焦点可见、图标名称、标签/错误关联、对比度和减少动态效果 |
| 数据一致性 | 慢旧请求不覆盖新条件，成功后列表/详情更新，失败无伪持久化 |
| 真实接口 | 非生产环境核对方法、参数、认证、响应、业务语义和用户结果 |

自动化无障碍工具不能替代键盘操作。模拟响应属于模拟验证，不得标为真实联调通过；生产环境不执行故障注入或测试数据写入。

## 6. 失败和证据

每个失败记录触发条件、预期、实际、来源或代码定位、影响和后续动作。`bug-fix` 无法复现时标记未确认；`refactor` 无法证明外部等价时标记未完成或待确认。

证据至少包含：任务/来源版本、实际路由、环境、命令及退出码、操作步骤、截图或脱敏请求记录、偏差和未验证项。Browser 不可用时给出逐区域自检和缺失原因，不把静态检查或模拟结果表述为页面真实验收。

## 7. 浏览器证据和会话隔离

使用 Browser/Playwright 或画像登记的等价能力进行真实页面验收。使用 `playwright-cli` 时必须在业务项目根目录运行，避免快照污染其他仓库；并使用命名会话 `-s=<task-id>` 隔离浏览器实例，避免并发任务抢占默认会话。若工具不支持 DPR、真机触屏或读屏播报，将对应项目记为 `unverified`，不能宣称已验证。
