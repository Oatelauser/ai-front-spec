# UI 公共组件目录（generic 预制模板）

这是框架中立的组件目录预制方案，适用于尚未确定 React/Vue 或不使用大型 UI 组件库的项目。它是候选，不是项目事实；用户选择后仍必须由 `$project-profile components` 使用 `$grill-me` 逐轮确认全部占位符（每个 `<待填写...>` 字段）。

## 选用与边界

- 优先复用 `implemented`；只缺少通用变体时扩展公共组件。
- 含业务状态机、角色、权限或接口语义的组件留在业务域。
- `planned` 可以指向尚不存在的未来目录，但必须记录规划依据和落地条件。
- 公共组件不直接请求业务接口，使用项目批准的 token、国际化和无障碍规则。
