# 验收证据模板

交付时先给结果，再填写适用证据；不适用项明确写“不适用”，无法完成项写“未验证”及原因。

```text
结果：
- [已完成 / 部分完成 / 被阻塞]
- [用户现在可以完成的事情]

范围：
- 文件/模块：[实际改动范围]
- 路由/接口：[实际目标]
- 未修改范围：[重要边界]

自动化：
- [命令] — [退出码与结果]
- [针对性测试] — [结果]
- [总质量门禁] — [结果]

浏览器验收：
- [视口、主题、路由] — [实际操作与结果]
- 键盘、焦点、溢出、可访问性、控制台 — [结果]

真实接口：
- 环境与测试数据：[不记录密钥]
- 主流程：[操作、预期、实际]
- 失败与权限：[操作、预期、实际]
- 刷新持久化：[结果]
- 停止在授权边界的动作：[如有]

变更审查：
- 无关修改：[无 / 说明]
- 秘密与敏感数据：[检查结果]
- 生成文件、重复基础设施和兼容性：[检查结果]

未验证项：
- [无，或具体阻塞、风险和继续条件]
```
