# 通用任务提示词

长期规则由 `AGENTS.md`、`$project-workflow` 和项目文档提供。单次任务只描述会改变结果的信息。

## 可直接使用

```text
使用 $project-workflow 完成本次任务，并按项目路由选择最小必要能力。

目标：
- [最终要改变什么]
- [用户完成任务后能做到什么]

上下文：
- [相关需求、文件、错误、路由、接口、数据或事实源]
- [已有实现、测试、日志或复现步骤]

约束：
- [必须保留的行为]
- [技术、安全、权限与授权边界]
- [不可修改的文件、目录、接口或外部系统]

完成条件：
- [可观察的功能或文档结果]
- [必须通过的针对性测试与总质量门禁]
- [适用的浏览器、接口、权限或真实环境证据]
- [允许保留的未验证项；没有则写“无”]
```

## 使用原则

- 能从仓库、需求、代码或测试查到的信息，不要求用户重复提供。
- 普通实现细节由代理按项目事实自主决定。
- 会扩大业务权限、执行不可逆动作、生产发布或外部联系的选择必须显式确认。
- 诊断任务只报告原因和证据，除非用户同时要求实施修复。
- 完成条件必须可观察、可验证，避免“优化一下”“做得更好”等无法验收的表述。
