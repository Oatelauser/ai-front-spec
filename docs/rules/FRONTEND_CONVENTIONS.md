# 前端通用约定

本文件是可选的前端领域规则。只有当 `docs/PROJECT_PROFILE.md` 已确认项目为前端项目，并明确了对应目录、组件、国际化、主题和数据层入口时，才启用本文件。项目画像中的实际路径、框架和已确认工程事实优先；本文件中的示例路径只作默认约定，不能替代项目事实。

## 启用与覆盖规则

- 在项目画像中登记本文件为“前端约定入口”；非前端项目写“不适用”。
- 接入前确认技术栈、图标入口、国际化入口、主题 token 入口、VO/adapter 目录、状态组件和文档目录。
- 既有项目约定与本文件冲突时，保留项目画像中已确认的约定，并把差异记录在项目画像或 `docs/design/<页面>.md`。
- 新规则先补测试、Lint 或校验脚本；无法机械判断的规则在代码审查和页面验收中检查。

## 图标

- 在 `index.html` 引入项目批准的 iconfont Symbol JavaScript；组件统一使用项目图标封装，例如 `<SvgIcon name="icon-xxx" />`。
- 图标 `name` 统一登记到项目画像声明的 constants 文件（默认 `src/constants/icons.ts`）；模板和业务逻辑不得写未登记的字面量。
- 设计源出现但 iconfont 没有的图标，先使用已登记的占位 `name` 接入，并在 `docs/design/<页面>.md` 的“待补图标”表登记名称、尺寸和出现位置。
- 未经项目画像和用户确认，不引入第二套图标库或用 emoji、内联绘制替代项目图标系统。

## 国际化

- key 使用 `<模块>.<页面>.<用途>` 格式并采用小驼峰。
- 新增文案同时补齐 `zh-CN` 与 `en-US`；英文按语义翻译，不用逐字占位翻译。
- 模板与逻辑代码禁止硬编码用户可见文案；语言包路径和加载方式以项目画像为准。
- 切换语言后检查长文本、表格、按钮、错误态和空态是否溢出。

## 主题

- 颜色、圆角、阴影和间距只能引用项目画像声明的 `tokens.scss` 或等价语义 token；组件内禁止写色值、裸圆角、裸阴影和裸间距字面量。
- 设计源只定义一种主题时，另一种主题按 `docs/design/<页面>.md` 的映射规则派生；没有确认映射时标记为待确认，不擅自臆测。
- 主题切换后检查组件、弹层、表格、图标、禁用态和错误态是否同步变更。

## 数据层

- 页面只依赖 VO；后端字段变化只允许在项目画像声明的 `types.ts` 与 `adapter.ts` 边界转换。
- 表格列、表单项和筛选项配置化，模板不重复写死字段结构。
- 枚举、字典和状态映射放入项目画像声明的 constants 目录，模板禁止魔法值。
- 列表和详情页必须实现 `loading`、`empty`、`error`、`unauthorized` 四态；React 项目优先复用 QueryState 或项目批准的统一状态组件，其他框架使用等价统一实现。
- API 函数命名采用“动词 + 业务名”，例如 `getOrderList`、`updateOrderStatus`；统一请求入口和错误归一化以项目画像为准。

## 代码卫生

- 命名贴合业务语义，例如 `orderList`，避免无上下文的 `list`、`data`、`items`。
- 注释使用中文，只解释业务意图、约束或特殊处理；不写与代码表面行为重复的注释。
- 禁止 `console.log`、`debugger` 和空 `TODO`；临时调试代码在交付前清理。
- mock 与示例数据使用真实感的中文业务数据；禁止 `John Doe`、`Lorem ipsum`、`example.com` 等占位内容。
- 单文件超过 300 行（React 组件超过 250 行）时拆分；如项目已有更严格限制，以项目画像为准。

## 文档产物

- `docs/design/<页面>.md`：记录 token 表、组件树、状态矩阵、图标清单、文案清单、主题派生规则，以及截图还原模式下的不确定值表。
- `docs/api/<模块>.md`：记录接口、入参、出参、枚举、错误码和对应 `types` 路径；来源标注“后端文档 <版本>”或“草案，待后端确认”。
- `docs/design/compare/<页面>/`：还原模式产出并排截图与差异清单；截图不得包含令牌、密码或未脱敏个人敏感数据。

## 页面验收补充

- 存量违例处置：既有代码与本约定冲突（如组件内色值字面量）时，**本次触达的文件顺手迁移到 token，未触达的存量不批量重做**；迁移与保留都在任务记录中标注，避免「新代码跟约定还是跟现状」的两难。
- 页面验收除项目画像矩阵外，必须检查图标登记、双语文案、token 引用、四态、配置化字段、极端数据和文档产物。
- 真实接口页面在非生产环境验证主流程、失败、权限拒绝和刷新持久化；mock、截图或 HTTP 200 不能单独证明流程通过。
