# 页面样式提取协议

基于 `$page-annotate` 捕获通道的样式提取扩展协议：把用户在真实页面上圈选的区域，提取为结构化「标准包」，用于照抄复现（copy）或留作参考（save）。本文档为**显式引用型**——不进入 AGENTS.md 路由图，仅当用户点名引用（如「按页面样式提取协议来」）时加载；`$page-annotate` 技能本体零扩展，本协议全部通过既有通道（注入、圈选、`read()`、ad-hoc evaluate、逐块截图）即兴完成。

## 定位与入口

| 用途 | 一句话 | 产物去向 |
| --- | --- | --- |
| copy 双页复现 | 「照着这个，现在就做进我开发中的页面」 | 开发页代码 + 并排对照图 |
| save 资料留存 | 「这页好看，存下来给以后页面用」 | `docs/design/references/` 条目 |

- 入口 = 用户显式引用本文档 + 表达 copy/save 意图。用户未引用、只说「搬过来」时，agent 即兴处理即可，不承诺按本协议落点。
- copy 的源页通常在**用户轨**（已登录的外网系统，Puppeteer 类工具进不去）；开发页在**隔离轨**（本地 dev server，agent 自由操作）。两轨浏览器 agent 同时持有。

## 标准包（每条标注的提取产物）

1. **多状态截图**：默认当前态；hover 等其他状态由用户亲手摆出来，agent 补截。
2. **子树 outerHTML**：标注框内各元素的 DOM 结构。
3. **筛过的 computed styles**：只取排版、字体、颜色、间距、边框、圆角、阴影、背景等核心属性（约 30 条），不取全量。
4. **同源 CSSOM 源规则**：`document.styleSheets` 可读时抓取源规则（含全部媒体查询）；跨域样式表读不到时如实报告，退回 computed styles 单断面。
5. **资产 URL 清单**：图片、图标、字体的地址与尺寸，标注哪些开源可落地。

## copy：双页复现循环

1. 用户轨打开源页：用户登录、导航到目标页，agent 注入 `$page-annotate` 标注器。
2. 用户圈选、提交、说「读」；agent `read()` 读回坐标与元素清单。
3. 按标注逐块 ad-hoc evaluate 提取标准包（守下文红线），**源证据一次取全落盘**。
4. 转 `$frontend-task` 在开发页（隔离轨 dev server）实现。
5. 开发页同区域截图，与源图**并排对照**，落 `docs/design/compare/<页面>/`。
6. 用户终拍板；后续迭代只对已落盘证据工作，**不再访问外部系统**。没有对照图不得宣称搬运完成。

## save：资料留存

- 落点：消费项目 `docs/design/references/<来源系统>-<区块>/`，与 `compare/`、`<特性>/vN/` 同族——`references` 存外部参考情报，不是本项目定稿。
- 条目结构：多状态截图 + 标准包数据 + 摘要 md（**功能规格**——控件、交互行为、适用场景，由 DOM 结构与观察整理成文字；**样式角色化**——原始值 `#0d9488` 加角色描述「主色」，复用时免二次翻译）。
- 日后实现页面时可直接引用条目作视觉依据。

## 提取红线

- **资产只取情报**：只回 URL 清单，不下载、不 base64 落盘；用户点名哪个资产才下哪个。
- **外部系统默认只读不点**：不自动点击、不切换状态；用户当轮明示「可以操作」后才能交互，授权按次有效，换页面换系统作废。
- **上下文节制**：ad-hoc evaluate 只查圈选区域的子树与关键样式，禁止整页 dump；大结果分块提取或直接落文件，不进对话上下文。
- **敏感把关**：登录态系统截图可能含真实业务数据，入 save 条目或交付物前请用户过目。

## 设计系统对账

copy 落地前先查 `docs/design/system/SYSTEM.md` 与 `docs/design/<特性>/vN/` 定稿：

- 无定稿：正常落地，样式值 token 化映射（外部值映射到项目 token，不硬编码）。
- 有定稿且外部样式冲突：亮出冲突让用户选——值映射到项目 token（保系统完整），或走既有 DRIFT 机制记漂移后按原样落地。

## 姊妹路由

- 自有资产、本地可访问页面的**整页**搬运 → `extract-static-html`（Puppeteer 整页快照，CSSOM 全量、图片内联），见 [能力安装清单](../capabilities.md)。
- 认证墙内或用户已登录的页面、以及**区域级**提取 → 本协议（用户轨）。

## 职责边界

实现阶段规则归 [前端任务规范](AI_FRONTEND_TASK.md)，交付证据格式归[验收证据模板](AI_ACCEPTANCE_EVIDENCE.md)；本文档只管捕获、提取、落点与对照。

## 已知天花板（如实告知用户）

- 「功能」是规格化描述（DOM 结构 + 观察 + 用户补充），不是对方源码。
- 跨域样式表 CSSOM 不可读，该部分退回单断面。
- Shadow DOM 不穿透。

## 设计决策

2026-09-30：专用提取器（`style-extract.js` 独立资产方案）经完整需求对齐后**未立项**——`$page-annotate` 既有通道 + ad-hoc evaluate 已覆盖能力，固化只买包装一致性。重启条件：即兴路径实战 2-3 次且出现具体痛点（上下文爆炸、提取不一致、落点漂移），届时再按本协议固化提取资产。
