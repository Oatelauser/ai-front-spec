## 二、适用域标签词表（3 值，封闭枚举）+ 激活条件表（机械映射）

| 标签 | 含义 | 激活条件（页面 targets 含…） | 典型条目 |
| --- | --- | --- | --- |
| `[容器]` | 页面运行在 WebView 容器 | `webview` | JSBridge 检测、OAuth code 流、旧内核 CSS 兜底 |
| `[视口]` | 移动端视口 | `mobileH5` | safe-area、16px 输入、等比背景坐标系 |
| `[全端]` | 恒适用 | 恒真 | 错误处理集中、安全最小暴露、ObjectURL 释放 |

**映射铁律：标签键名 = `deliveryTargets` 键名**——同一套词，选端时选的是什么，标签激活就查什么，零翻译层、零解释空间。正交不推导：钉钉 PC 内嵌页是 `webview`×桌面视口，[容器] 激活而 [视口] 不激活，各查各的键，不做隐含推断。

## 三、页面声明：`route.meta.targets` 约定（三层缝合的第三层）

```ts
meta: { targets: ['webview'] }             // 仅容器页面：全标签硬约束
meta: { targets: ['browserWeb'] }          // 仅浏览器页面：[容器] 条目豁免
meta: { targets: ['browserWeb', 'webview'] }  // 多端共享页（如登录页）：全标签生效
// 省略 → 缺省跟随项目主端（deliveryTargets 中 user-confirmed 的集合）
```

规则：
1. **缺省跟随主端**：主端含 webview → 全标签生效；主端纯浏览器 → `[容器]` 条目自动降为背景知识（可参考、不强制、不删除）。`[视口]` 条目在纯 desktop 页面同理降级。
2. **显式声明覆盖缺省**，仅作用于该页面。
3. 页面声明写不进路由生成机制的，落在手写路由 meta 或页面级常量——成品文档只约定语义，不绑死实现载体。

### 标签判定协议（AI 识别的机械解，写进成品文档头；frontend-task inspect 阶段执行）

1. **读项目主端**：`.codex/profile-state.json` 的 `deliveryTargets`，取 user-confirmed 集合（AGENTS.md:17 本就强制每阶段读，零新读点）
2. **读页面声明**：当前任务目标页面的 `route.meta.targets`；缺省 = 第 1 步的主端集合
3. **查激活条件表**（第二节）→ 得**本页生效标签集**；未激活标签的条目 = 背景知识（可见、不强制）
4. **生效标签集写进 plan 开头一行**（如 `本页生效标签：容器+视口+全端`）——落纸才可核对：verify 阶段复查"生效标签 ↔ 页面声明"一致性，写错了看得见

**分层职责**：AGENTS.md 路由行管第一层（整本文档挂不挂载，按 deliveryTargets 状态）；本协议管第二三层（条目标签 × 页面声明 → 哪几类是硬约束）。各管一段，不重叠。

**worked example**（写进成品文档头，照抄可执行）：
- 项目主端：browser + mobileH5 + webview 全确认
- 页面 A（登录页）`targets: ['browserWeb','webview']` → 生效 = 容器+全端。若登录页还须在手机上显示好，声明里加 `mobileH5`——**声明即事实**，声明里没有的端，对应标签就不激活，不做"应该也算手机吧"的推断
- 页面 B 省略 → 缺省 = 主端全集合 → 生效 = 容器+视口+全端
- 页面 C（钉钉 PC 内嵌）`targets: ['webview']` → 生效 = 容器+全端（PC 是桌面视口，视口不激活）

## 五、去私有化改写样例（28 条，覆盖 8 域 × 3 标签）

写法：`- [标签] 成品条文`（源：分类表对应行）。执行期按此风格写全部条目。

### 域 1 视口与全屏
- [全端] 全屏高度统一使用全局全屏高度类（100vh 兜底 + 100svh 覆盖），禁止裸写 svh/100vh 工具类（源：h-app-screen 条）
- [视口] 沉浸式页面 viewport 锁缩放 + viewport-fit=cover；visualViewport 同步只在全局注册一次，单页面不得重复注册（源：沉浸页条）
- [视口] 贴边控件用 safe-area/calc 做边界约束；图标+文案复合控件预留整体宽高防裁切（源：不只以桌面 Chrome 为依据条）
- [视口] 带热点背景保持等比坐标系，禁独立 scaleX/scaleY 与 fill 拉伸；长短屏明确裁切或滚动策略（源：热点背景条）
- [视口] Apple 系设备输入控件字号不小于 16px 防聚焦缩放；placeholder 样式必须作用到真实 input/textarea（源：16px 条）

### 域 2 布局与组件层
- [全端] 常规页/页头/沉浸页优先使用全局布局组件（head/main 结构 + 插槽定制），不自建页面骨架（源：page-layout/page-head/login-layout 条）
- [全端] 统一返回按钮内建空历史判断与兜底路由；返回逻辑先判空历史再 back，有业务入口的页面显式指定兜底（源：BackButton/canGoBack 条）
- [全端] 页面私有组件放页面目录，跨页复用才提升全局；新增组件先判断归属层级（业务包装层/公共层/基础包/页面私有）（源：组件归属两条合并）
- [全端] 弹窗/抽屉/Toast/Dialog 反馈走项目统一入口，不散落组件库 API；业务反馈走统一消息工具（源：Vant/message 条）
- [全端] 异步确认契约：统一确认入口支持异步 onOk，期间仅确认按钮 loading、失败保持打开，异步期间不禁用取消（源：confirm onOk 条）

### 域 3 请求与认证
- [全端] 请求统一走项目封装层（成功码/Token 头/错误提示集中处理）；业务层不重复 try/catch，不在业务页手写 axios/fetch（源：封装三层分工 + 手写禁令合并）
- [全端] 按封装层返回结构统一解构（如 `{ error, data }`），先判 error 再用数据（源：解构条）
- [容器] 企业容器 OAuth：后端换 Token，前端只收短时 code/state；处理完用 router.replace 清理地址栏敏感参数（源：OAuth + 清参数合并）
- [全端] 认证逻辑复用认证 store 既有 action 链，不另起炉灶；401/登出码走统一登出重置，页面不重复跳转（源：auth store + 401 条）
- [全端] 多页面共用接口数据沉淀全局 store；缓存刷新时机明确（登出、401、切用户必清）（源：store 缓存条）

### 域 4 安全与最小暴露
- [全端] 后端富文本/评论/用户 HTML/外链/文件名一律按不可信内容处理；富文本渲染走统一清洗组件，不新增裸 v-html（源：不可信 + v-html 合并）
- [全端] token/权限码/租户信息不入 URL/错误提示/前端日志；二维码/订单号等凭证不暴露完整值（源：token 不入 + 凭证条合并）
- [全端] 外链仅允许协议白名单（http/https/mailto），新窗口补 rel="noopener noreferrer"；redirect 仅允许站内相对路径（源：外链 + redirect 合并）
- [全端] createObjectURL 的预览地址在替换/删除/卸载时释放；表单保存后端文件标识，不存 blob URL/base64（源：ObjectURL + 文件 id 合并）
- [容器] WebView 注入的 query/hash/JSBridge 返回值按外部输入处理；code/state/tenantId/corpId 不入日志/Toast/外链/缓存（源：注入参数条）

### 域 5 资源与媒体
- [全端] 设计稿位图按 4x 导出、SVG 保持矢量；高清整屏位图按最大 CSS 尺寸 × DPR（iOS 常 3）核对源像素，压缩不替代源图（源：Figma + DPR 合并）
- [全端] 文件展示优先用直链工具（loading 不等图片），须读 Blob 才用文件流工具并按生命周期释放（源：文件 id 直链条）
- [全端] 动图/动画复用公共播放组件与工具，不引入裸放实现；新资源类型先确认打包归类与缓存策略（源：APNG/PAG 通用化 + 大资源条）

### 域 7 WebView 能力与兼容
- [容器] 企业 WebView 容器一律按能力不完全一致处理（现代 CSS/History/视口/摄像头）（源：容器能力条）
- [容器] 环境判断集中于统一模块并暴露语义函数，不散落 UA 判断；JSBridge/SDK 先存在性/能力检测再懒初始化，页面只调封装（源：两条合并）
- [容器] 旧内核 CSS 兜底集中维护在全局样式入口（translate/color-mix/bg-clip-text/svh/透明遮罩高风险点），不只依赖构建插件自动降级（源：CSS 兜底两条合并）
- [容器] WebView 登录授权页空历史用显式 router.replace/push 兜底，防 back 直接退出容器（源：空历史兜底条）

### 域 8 验收
- [全端] 交付前 320–450px 多断点 + 连续宽度抽查，尽量真机复核（源：验收抽查条）
- [容器] WebView 适配验收必须包含目标容器真机（模拟器测不出内核差异）（源：真机复核条，新增成文）
